Small, focused examples and tools.

## NGINX examples

- [TLS-mutual-auth-complete-NGINX](https://github.com/heroicode/TLS-mutual-auth-complete-NGINX): a complete, self-contained example of TLS mutual authentication
- [proxy_pass-dummy-NGINX](https://github.com/heroicode/proxy_pass-dummy-NGINX): a fairly minimal demonstration of `proxy_pass` behavior
- [file-upload-only-NGINX](https://github.com/heroicode/file-upload-only-NGINX): upload files using only NGINX
- [faketime-NGINX](https://github.com/heroicode/faketime-NGINX): configure NGINX to work with faketime

## Tools

- [pdf-booklet](https://github.com/heroicode/pdf-booklet): convert PDF files into booklet format for multi-page printing
- [project-generator](https://github.com/heroicode/project-generator): a really simple project generator template system
